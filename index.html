Модульная архитектура: resilient-batch-signer.js • Без React

Отказоустойчивое подписание КриптоПро в Internet Explorer

Ядро логики вынесено в отдельный независимый JS-модуль resilient-batch-signer.js. Модуль контролирует зависания диалогов PIN и COM, предотвращает утечки памяти и автоматически возобновляет подписание с прерванного документа.

Управление пакетом Ожидание
Сторожевой таймер зависаний (Watchdog): Мониторинг активен (1 сек)
Время текущего документа: 0.0 с Лимит таймаута: 5.0 с Авто-перезапусков: 0
Прогресс: 0 / 8 документов
Память IE (32-bit): 195 МБ
Проверка модуля и вызовов сбоев:
Очередь документов LocalStorage Checkpoints
Журнал событий процесса, Watchdog и криптопровайдера
Файл resilient-batch-signer.js (Отдельный модуль)

Этот модуль подключается в любую веб-страницу через <script src="resilient-batch-signer.js"></script> или импортируется через CommonJS/AMD. 


    

  


  
  

    

      

        Матрица кодов ошибок COM и алгоритмы восстановления
      

      

        
          

            Код / Состояние
            Название
            Причина в IE / КриптоПро
            Действие модуля ResilientBatchSigner
          

        
        
          

            DEADLOCK / HANG
            PROCESS_HUNG_STALLED
            Окно ввода PIN (cpui.dll) потеряло фокус, застряло за другими окнами или драйвер завис.
            Сторожевой таймер фиксирует превышение лимита, аннулирует старый дескриптор, вызывает CollectGarbage() и автоматически перезапускает подписание.
          

          

            0x800706BA
            RPC_S_SERVER_UNAVAILABLE
            Падение фонового процесса cpcsp/cades. Обрыв соединения COM.
            Занулить ссылки (obj=null), вызвать CollectGarbage(), пауза 2 сек и авто-повтор документа.
          

          

            0x8007000E
            E_OUTOFMEMORY
            Исчерпание 32-битного адресного пространства 2 ГБ из-за Base64 BSTR строк.
            Пакетирование по 2-10 файлов, зануление COM объектов и принудительный сбор мусора.
          

          

            0x80090016
            NTE_BAD_KEYSET
            Токен извлечен из USB-порта во время пакета.
            Сохранение контрольной точки, перевод пакета на паузу, ожидание повторного подключения токена.
          

        
      

    

  


  
  

    

      

        Интеграция модуля ResilientBatchSigner в проект
      

      

        
1. Подключение скрипта

        
<script src="resilient-batch-signer.js"></script>


        
2. Создание экземпляра с коллбеками

        
var signer = new ResilientBatchSigner({
  documents: [
    { id: "DOC-1", name: "УПД_№8412.xml", base64: "PHJvb3Q+..." },
    { id: "DOC-2", name: "Акт_№109.xml", base64: "PHJvb3Q+..." }
  ],
  certThumbprint: "38FA5B74D1C35502A5092BC18C2C94FA5E6D8A12",
  timeoutSec: 30, // лимит ожидания до авто-перезапуска
  onProgress: function(index, total, doc) {
    console.log("Прогресс: " + index + " из " + total);
  },
  onDocSigned: function(doc, sig) {
    console.log("Подписан: " + doc.name);
  },
  onHangDetected: function(doc, sec) {
    console.warn("Зависание на " + doc.name + "! Авто-перезапуск...");
  },
  onComplete: function(summary) {
    alert("Все документы успешно подписаны!");
  }
});

// Старт пакета
signer.start();
